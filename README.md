# Structural Uncertainty UVIF

**Non-Compensatory Equilibrium and Optimization-Pressure Dissipation: A Control-Barrier Framework for Self-Modifying Systems**

This repository provides the reproducibility materials for the UVIF structural-uncertainty and recursive self-improvement safety demonstration. It includes an abstract self-modification model, non-compensatory equilibrium-index simulations, control-barrier acceptance rules, and figure/table generation scripts supporting the manuscript.

## Repository link title

**Structural Uncertainty UVIF — Reproducibility Repository**

## Short description

Reproducible Python artifacts for the UVIF equilibrium-gated self-modification framework, showing how non-compensatory aggregation and control-barrier filtering can prevent single-pressure collapse under optimization pressure.

## Contents

- `UVIF_structural_uncertainty_demo.ipynb` — main notebook for simulations and figures.
- Numerical comparison of geometric-mean and weighted-sum barriers.
- Experiments on bounded risk, aggregator families, corrupted measurement channels, and threshold robustness.
- Scripts and fixed seeds for reproducibility.

## Manuscript context

The associated manuscript develops the Unified Variational Intelligence Framework (UVIF) equilibrium index as a weighted geometric mean of five normalized pressure-health functions: capability, risk, uncertainty, interpretability, and constraint. The repository supports the computational illustrations used to compare non-compensatory and compensatory safety gates.
